# Art Space

Учебный проект на Kotlin и Jetpack Compose по [методичке Android Developers](https://developer.android.com/codelabs/basic-android-kotlin-compose-art-space).

В приложении три оригинальные векторные иллюстрации: «Горное озеро», «Закат над морем» и «Лесная тропа». Они созданы для этого проекта и находятся в `app/src/main/res/drawable`. «Студия Art Space» — условное название автора коллекции, 2026 — год создания иллюстраций. Внешние изображения и подключение к интернету приложению не нужны.

## Прототип

Телефон в вертикальной ориентации:

```text
┌───────────────────────────────┐
│                               │
│     Изображение в рамке        │
│                               │
├───────────────────────────────┤
│ Название работы               │
│ Автор (год)                   │
│ Работа 1 из 3                 │
└───────────────────────────────┘
    [ Назад ]      [ Далее ]
```

На широком экране (от 600 dp, когда ширина больше высоты) изображение находится слева, описание и кнопки — справа. На маленьких экранах содержимое можно прокрутить.

## Соответствие методичке

- `ArtworkWall`: `Image`, описание для TalkBack, рамка и тень через `Surface`.
- `ArtworkDescriptor`: название, автор и год через `Text`.
- `DisplayController`: две кнопки внутри `Row`.
- `ArtSpaceScreen`: размещение блоков через `Column` или `Row`, состояние выбранной работы через `rememberSaveable`.
- «Далее» после последней работы открывает первую; «Назад» с первой открывает последнюю. Изображение и подписи обновляются вместе.
- При повороте экрана выбранная работа сохраняется. Есть Compose Preview телефона и планшета.

## Запуск и проверка

Откройте проект в Android Studio, дождитесь Gradle Sync и запустите конфигурацию `app` на эмуляторе или устройстве с Android 7.0 (API 24) или новее.

```powershell
./gradlew.bat :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Проверка на подключённом устройстве или запущенном эмуляторе:

```powershell
./gradlew.bat :app:connectedDebugAndroidTest
```

`ArtSpaceScreenTest` проверяет смену изображения и подписей, циклический переход в обе стороны и восстановление выбранной работы после пересоздания Activity. Для визуальной проверки откройте `ArtSpacePreview` и запустите приложение на телефоне и планшете в обеих ориентациях.
